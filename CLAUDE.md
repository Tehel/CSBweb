This is the DMweb project.

Its aim is to produce a fully compliant Typescript equivalent of the CSBwin project (C++ source code in doc/CSBwin-src" directory), using a Canvas in a web page as viewport. We will *always* aim at keeping the logic as close to the one implemented in the reference C++ implementation of CSBwin project.

The documentation lives in the "doc" directory, where all or findings about the CSBwin source code are recorded, refer to it anytime you need. When you do inspect the CSBwin source code and find relevant and 100% sure facts that were not there already, be sure to update the documentation for later use.

You must follow the guidelines starting from `./AGENTS.md` before generating, reviewing code, or doing any task on this project.
